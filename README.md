# CineRate 🎬

CineRate is a full-stack movie review web application where users can explore trending movies, search for films, view movie details, and submit ratings and reviews.

The project uses the TMDB API for movie data and provides a responsive frontend with user authentication and profile features.

---

## 🚀 Features

### 🔐 Authentication
- User Registration
- User Login
- JWT-based Authentication
- Logout functionality

### 🎥 Movie Features
- View Trending Movies
- Search Movies
- View Detailed Movie Information
- TMDB API Integration

### ⭐ Review System
- Submit Ratings and Reviews
- One Review Per User Per Movie
- View Reviews from Other Users
- Username displayed with reviews

### 👤 User Profile
- Profile Section with Username & Email
- Review Count
- View Previously Reviewed Movies
- Latest Reviews Displayed First

### 🎨 Frontend
- Responsive UI
- React Router Navigation
- Dynamic Movie Pages
- Interactive Review System

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router
- Axios
- CSS

### Backend
- FastAPI
- Python
- JWT Authentication
- TMDB API

### Database
- SQLite (Authentication Data)
